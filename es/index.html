3. Servicios de Firebase (Google LLC)

Usamos Firebase, un servicio de Google LLC (EE. UU.). La transferencia de datos a EE. UU. se realiza sobre la base de las Cláusulas Contractuales Tipo de la UE (SCC). Más información: firebase.google.com/support/privacy

4. API de PlantNet

Para la identificación de plantas enviamos fotos a la API de PlantNet del CIRAD (Francia). Las fotos se tratan según los términos de uso de PlantNet y pueden usarse para mejorar su base de datos. No se transmiten datos personales (nombre, correo) a PlantNet.

5. Datos de ubicación

El acceso a la ubicación es opcional y sirve exclusivamente para consultar datos meteorológicos locales para los recordatorios de riego. Los datos de ubicación no se almacenan ni se comparten con terceros. Puedes revocar el permiso de ubicación en cualquier momento en los ajustes del dispositivo.

6. Conservación y eliminación de datos

  • Los datos de la cuenta se conservan hasta que elimines tu cuenta.
  • Los datos de plantas y fotos se eliminan por completo a petición.
  • Los datos de Analytics se eliminan automáticamente tras 14 meses (predeterminado de Firebase).
  • Los datos de Crashlytics se eliminan tras 90 días.

7. Tus derechos (RGPD)

Tienes derecho a: acceso (art. 15), rectificación (art. 16), supresión (art. 17), limitación (art. 18), portabilidad (art. 20), oposición (art. 21) y a presentar una reclamación ante la autoridad de control competente. Para ejercerlos, escribe a: fadymerey.fm@gmail.com

8. Seguridad de los datos

Todos los datos se transmiten mediante conexiones cifradas (HTTPS/TLS). Los datos locales sensibles se protegen con Android EncryptedSharedPreferences. Las reglas de seguridad de Firestore garantizan que los usuarios solo puedan acceder a sus propios datos.

9. Menores

PlantCare está dirigido a personas de 13 años o más. No recopilamos a sabiendas datos de menores de 13 años.

10. Cambios en esta política

Nos reservamos el derecho de actualizar esta política. Ante cambios sustanciales, se te notificará dentro de la app. La fecha de la última modificación se indica arriba.
