3. اقتبس أوامر grep المتوقّعة قبل وبعد.
4. **اطلب موافقة Fady** قبل البدء فقط إذا كانت المهمة تحتاج قراراً (مثل F5 الذي يحتاج تأكيداً على بنية CSV الجديدة، أو A4 الذي يحتاج اختياراً بين تنزيل TFLite أو إخفاء الميزة). للمهام الواضحة، ابدأ مباشرة.
